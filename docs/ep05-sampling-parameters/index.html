What temperature to use

Extraction, classification, code, maths0 – 0.3
Q&A, summaries, chat0.3 – 0.8
Brainstorming, creative writing0.8 – 1.2
Production systems≤ ~1.2

Start with the provider default. Change it only with a reason, and test.

GenAI #5 · Sampling parameters

Top-p = 0.9: keep the likely few

  • Top-p: keep tokens until their odds add up to p. Here, 4 tokens = 90.3%.
  • Top-k: keep a fixed number, e.g. 40.
  • Dropped tokens can never be picked.
  • Tune temperature or top-p, not both.

Interview question · FDE

“A customer's extraction pipeline returns slightly different JSON every run, and sometimes cuts off halfway. What do you check?”

A strong answer

Two problems. Cut-off JSON: check the finish reason. If it's the length limit, raise it, and remember thinking counts. Variation: lower temperature, leave top-p alone, but don't rely on zero being deterministic. Use structured outputs, validate every response, retry on failure, and use a seed for repeatable tests.
