Closed vs open-weight

Closed · API-only

Call the provider's API

Claude, GPT, Gemini

  • Most capable, nothing to host
  • Per-token cost
  • Data leaves your network
  • Models get updated or retired

Open-weight · download it

Run it anywhere

Llama, Gemma, Qwen, Mistral, DeepSeek

  • Data stays with you, works offline
  • Can fine-tune it
  • You run the hardware
  • Small ones are less capable

Open-weight ≠ open source: you get the weights, not the training data · licences vary

Three ways to run a model

Provider API

Anthropic, OpenAI, Google AI Studio

Fastest start, newest models first. Data goes to the provider.

Cloud platform

Bedrock, Vertex AI, Azure AI Foundry

Many models, one bill, your cloud's IAM and regions. What most enterprises use.

Self-host

Ollama, vLLM

Open-weight only. Full control and privacy; you run the hardware.

Same model, different doors: Claude is on Anthropic's API, Amazon Bedrock and Google Vertex AI.

Interview question · FDE

“Which LLM should we use?”

A strong answer

It depends on the job, so I start with questions: the task, what good looks like, cost and latency targets, and whether data can leave their network. If not, open-weight in their environment. Then I shortlist two or three models across tiers, test them on 20–50 real examples, and measure quality, cost and latency. We pick the smallest model that passes, keep it behind config so it's swappable, and re-test when new models ship.
