Four providers, two ways to authenticate

Anthropic

API key from the Console

API Keys → Create Key → copy once. Set a spend limit under Limits.

ANTHROPIC_API_KEY

OpenAI

API key from the Platform

A dedicated project → API keys → create secret key. Set a budget.

OPENAI_API_KEY

Google Gemini

API key from AI Studio

Get API key → Create API key in a Cloud project. Set a budget alert.

GEMINI_API_KEY

AWS Bedrock

Your AWS identity

No single key: an AWS profile via SSO or IAM, plus model access in your region.

AWS_PROFILE

All pay-as-you-go: set a spending limit on every account today.

AWS Bedrock in three steps

01 · Credentials

Configure an AWS profile

# preferred
aws configure sso --profile genai-course
# personal dev account
aws configure --profile genai-course
# check who you are
aws sts get-caller-identity --profile genai-course

02 · Region + access

Check model access

Pick a Bedrock region (I use us-east-1). Some providers need a one-time access request or use-case form.

03 · Model ID

Copy it into .env

Take the model or inference profile ID from the catalog. Never hardcode it.

Model versions change often, so every model name lives in .env, not in code.

GenAI #2 · Dev Environment Setup

Five rules for API keys

  1. 01Never hardcode a key in a .py file or notebook, not even for a test
  2. 02.env goes in .gitignore before you create the file
  3. 03Commit a .env.example with names and fake values only
  4. 04Least privilege + limits one key per project, spend caps, short-lived AWS creds
  5. 05Leaked? Revoke immediately. Deleting the commit isn't enough.

GenAI #2 · Dev Environment Setup

Smoke test: one call per provider

hello_anthropic.py

import os
from dotenv import load_dotenv
import anthropic

load_dotenv()
client = anthropic.Anthropic()  # reads ANTHROPIC_API_KEY

msg = client.messages.create(
    model=os.environ["ANTHROPIC_MODEL"],
    max_tokens=200,
    messages=[{"role": "user",
               "content": "Say hello in one sentence."}],
)
print(msg.content[0].text)

run all four

uv run python hello_anthropic.py
uv run python hello_openai.py
uv run python hello_gemini.py
uv run python hello_bedrock.py

if it fails

401 / auth error → key in .env
AccessDenied (Bedrock) → model access or IAM
429 (Gemini) → free-tier rate limit
KeyError → variable missing from .env

OpenAI, Gemini and Bedrock (Converse API) versions are in the repo, same pattern.
