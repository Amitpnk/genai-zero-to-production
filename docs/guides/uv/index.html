What is uv?

One tool that replaces pip, venv, pip-tools, pyenv and pipx. Made by Astral, the team behind Ruff.

JobOld wayWith uv
Install Python versionspyenv, python.org installeruv python install 3.12
Create a virtual environmentpython -m venv .venvdone for you by uv sync
Install packagespip install …uv add …
Pin exact versionspip freeze > requirements.txtuv.lock, automatically
Run in the environmentactivate, then runuv run …, no activation
Run a CLI tool oncepipx run …uvx …

Why this series uses it

  • Much faster than pip
  • Installs Python for you, even if your system Python is old
  • A lock file: everyone gets identical versions

Good to know

  • Your system Python is never touched
  • uv pip … still works for old projects
  • No activation: just prefix commands with uv run

How a uv project fits together

You describe what you want; uv pins it, installs it and runs inside it.

  • You never edit uv.lock or .venv by hand. uv keeps them in step with pyproject.toml.
  • uv run checks everything's in sync first, so it's always safe to use.

2 · The five commands you'll use every day

If you only learn five, learn these.

3 · Projects, dependencies and running

Everything else you'll reach for.

Projects and dependencies

uv init my-app --python 3.12

New project: pyproject, .python-version, README, .gitignore, src/ and a git repo

uv add "openai>=2,<3"

Add with a version range

uv add --dev ruff pytest

Development-only tools (the dev group)

uv sync --no-dev

Install without dev tools, e.g. in production

uv lock --upgrade-package openai

Upgrade one package to its newest allowed version

uv lock --upgrade

Upgrade everything, then re-run your tests

uv export --format requirements-txt

A requirements.txt for tools that need one

Running things and tools

uv run python

A Python shell with the project's packages

uv run --with rich python script.py

Add a package for this one run only

uvx ruff check .

Run a CLI tool without installing it (uvx = uv tool run)

uv tool install ruff

Install a CLI tool permanently, isolated from projects

uv tool list

List installed tools

uv cache size --human

Disk used by the download cache (e.g. 340.9 MiB)

uv cache clean

Clear the cache (safe: packages re-download when needed)

4 · Python versions

uv installs Python per user, with no admin rights, and never touches your system Python.

Commands

uv python install 3.12

Download and install Python 3.12

uv python list --only-installed

Every Python uv can see on this machine

uv python pin 3.12

Write .python-version so this project uses 3.12

uv python find

Which Python would be used here?

Real example: an old system Python

cpython-3.12.15   ← installed by uv
cpython-3.8.2     ← old system Python

Both live side by side. python --version still says 3.8.2; uv run python --version says 3.12. Nothing else on the machine changes.

6 · Commit or not?

Three files in, one folder out.

FileCommit?Why
pyproject.tomlYesWhat the project needs
uv.lockYesEveryone gets identical versions
.python-versionYesEveryone uses the same Python
.venv/NeverMachine-specific, large, rebuilt by uv sync (it's in .gitignore)

VS Code: run uv sync once, then Ctrl+Shift+P → Python: Select Interpreter → pick the one inside .venv. Red squiggles under imports usually mean the wrong interpreter.

7 · Troubleshooting

The usual suspects.

ProblemFix
uv not found / not recognizedClose and reopen the terminal. Still missing? Re-run the installer, or check ~/.local/bin is on your PATH
ModuleNotFoundErrorUse uv run python …, not plain python …; or run uv sync
python --version shows an old versionNormal: that's your system Python. uv run python --version shows the project's
No solution found when resolving dependenciesConflicting version needs: loosen a range in pyproject.toml, then uv lock
Out of date after git pulluv sync
Running out of diskuv cache clean
Corporate proxy or certificate errorsSet UV_NATIVE_TLS=1 to use your system's certificates, or set HTTPS_PROXY

Clean start (safe: .venv is rebuilt from uv.lock)

rm -rf .venv          # Windows PowerShell: Remove-Item -Recurse -Force .venv
uv sync
