What is Ollama?

It runs open-weight models (Gemma, Llama, Qwen, Mistral…) locally. No API key, no cloud bill, and your prompts never leave your machine.

Why use it

  • Free and works offline
  • Private: data stays on your machine
  • Great for learning and quick experiments

Why not always

  • Small local models are less capable than Claude, GPT or Gemini
  • Big models need lots of RAM, ideally a GPU
  • You manage downloads and memory
  • A model is downloaded once (disk), loaded into memory on first use, and unloaded after 5 minutes idle.
  • The CLI, your code and other apps all talk to the same server.

1 · Install and run your first model

Download from ollama.com/download, or use a package manager.

Install

winget install Ollama.Ollama

Windows

brew install ollama

macOS

curl -fsSL https://ollama.com/install.sh | sh

Linux

ollama --version

Check it worked

First model start here

ollama pull gemma3:1b

Download once, about 815 MB

ollama run gemma3:1b

Chat with it. Type /bye to exit.

ollama run gemma3:1b "Why is the sky blue?"

One question, one answer, then exit

2 · Manage and run models

Everything you need day to day.

Download and manage

ollama list

All downloaded models, with size and date

ollama pull gemma3:1b

Download a model, or update it

ollama show gemma3:1b

Details: parameters, context length, quantization

ollama cp gemma3:1b my-gemma

Copy under a new name

ollama rm gemma3:1b

Delete a model and free its disk space

Run

ollama run gemma3:1b

Interactive chat (downloads first if needed)

ollama run gemma3:1b --verbose

Also show speed: tokens per second, load time

ollama run gemma3:1b --keepalive 30m

Keep it in memory for 30 minutes after use

ollama run gemma3:1b --format json "List 3 colours"

Ask for a JSON response

3 · See what's running, and stop it

ollama stop unloads a model. Quitting the app stops the whole server.

Running models

ollama ps

What's loaded now: memory used, CPU/GPU, time until unload

ollama stop gemma3:1b

Unload a model from memory immediately

4 · Inside an interactive chat

Type these after ollama run <model>.

TypeWhat it does
/?Show all chat commands
/byeExit the chat (or press Ctrl+D)
/clearForget the conversation so far
/show infoDetails of the current model
/set system "You are a pirate."Set a system prompt
/set parameter temperature 0.2Change a setting for this session (temperature is Episode 5)
/set parameter num_ctx 8192Bigger context window (uses more memory)

Slash commands work only inside the interactive chat. If you pipe text in (echo "/bye" | ollama run …), the model treats it as a normal prompt.

5 · Use Ollama from code

Ollama speaks its own API and the OpenAI API, so the openai package from Episode 2 works unchanged.

OpenAI-compatible (Python)

from openai import OpenAI

client = OpenAI(base_url="http://localhost:11434/v1",
                api_key="ollama")  # any non-empty key
reply = client.chat.completions.create(
    model="gemma3:1b",
    messages=[{"role": "user",
               "content": "Say hello in five words."}],
)
print(reply.choices[0].message.content)

Test locally for free, then switch base_url and model to a cloud provider.

Native API (curl)

curl http://localhost:11434/api/chat -d '{
  "model": "gemma3:1b",
  "messages": [{"role": "user",
                "content": "Say hello in five words."}],
  "stream": false
}'
On Windows PowerShell? 
$body = @{ model = "gemma3:1b"; stream = $false
  messages = @(@{ role = "user"; content = "Say hello in five words." }) } | ConvertTo-Json -Depth 5
Invoke-RestMethod http://localhost:11434/api/chat -Method Post -Body $body -ContentType "application/json"

In Windows PowerShell, curl is an alias for Invoke-WebRequest.

EndpointDoes
POST /api/chatChat with messages
POST /api/generatePlain text completion; supports logprobs (used by Episode 3's next_token.py)
POST /api/embedEmbeddings, with an embedding model such as nomic-embed-text
GET /api/tagsDownloaded models (same as ollama list)
GET /api/psLoaded models (same as ollama ps)
/v1/…OpenAI-compatible endpoints

6 · Memory: how much do I need?

Disk is used once per downloaded model. RAM (or GPU memory) is used only while a model is loaded.

Model sizeExampleRAM while loadedRuns well on
~1Bgemma3:1b~0.9 GB (measured)Any laptop with 8 GB
~4Bsmall general models~3–4 GB8–16 GB laptop
~12Bmid-size models~8–10 GB16 GB+ or a GPU
~27B+large models17 GB+32 GB+ or a big GPU

Approximate for the default 4-bit (Q4_K_M) downloads. A bigger context window needs more memory. Save memory with ollama stop <model> when you're done, and run one model at a time.

8 · Troubleshooting and clean-up

Most problems are a stopped server or a model that's too big.

ProblemFix
could not connect to ollama server / ConnectionRefusedErrorServer isn't running: open the Ollama app, or run ollama serve
model 'gemma3:1b' not foundollama pull gemma3:1b
Very slow repliesModel too big for your machine: try a smaller one, close other apps
Laptop runs out of memoryollama ps, then ollama stop <model>
Disk filling upollama list, then ollama rm <model>
Port 11434 already in useAnother Ollama is running: quit it first

Clean up

ollama ps                  # anything loaded?
ollama stop gemma3:1b      # unload it
ollama list                # what's on disk?
ollama rm gemma3:1b        # delete it (frees ~815 MB)
