Same text, different token counts

  • English is cheapest: about 4 characters per token.
  • Code, JSON, numbers and other languages cost more per character.
  • Gemini splits numbers digit by digit: 45 characters → 46 tokens.
  • Always count with your model's tokenizer.

Even when it fits: lost in the middle

  • Models use facts at the start and end of long prompts more reliably than ones in the middle.
  • Put key instructions and facts first or last.
  • Better still: send less. Only what the question needs.

Illustrative · based on “Lost in the Middle” (Liu et al., 2023)

  • Cost and latency snowball as chats get longer.
  • Multiply by every user, every day.

GenAI #4 · Tokens and context windows

Interview question · FDE

“Our support chatbot gets slower and pricier as conversations grow, and forgets what users said at the start. Why, and what do you do?”

A strong answer

The model has no memory, so every turn resends the whole chat: input tokens snowball, so cost and latency rise. Past the context window, the oldest messages are trimmed, so it forgets. Measure token usage per turn, then keep recent turns plus a summary, retrieve only relevant knowledge, cap output, and cache the fixed system prompt.
